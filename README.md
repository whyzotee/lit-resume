# Lit Resume

A resume site built with Lit, Vite, and Tailwind CSS. The build generates static files in `dist/`.

## Usage

Use the scripts in `package.json` to develop, build, and test the site.

Edit the resume in `src/components/` and `public/data/profile.json`. Styles are in `src/style.css`.

Deploy `dist/` to a static host after building.
